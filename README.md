# SOMA Schedule Reader

Offline, single-file reader and analyser for Primavera P6 (XER, XML) and
Microsoft Project (XML) schedules. Everything runs in the browser — nothing
is uploaded, and the schedule never leaves your machine.

**Latest:** https://somastevie.github.io/soma-schedule-reader/

**Every version:** https://somastevie.github.io/soma-schedule-reader/versions.html

This repository holds only the built viewers. The version is shown
bottom-left of the status bar and on the opening screen.

The viewer asks for a licence key before it opens a schedule. Contact
SOMA Project Controls for one.
